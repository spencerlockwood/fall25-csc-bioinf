This assignment involved implementing four sequence alignment algorithms (global, local, semi-global, and affine gap penalty) in both Python and Codon. The goal was to compare performance between interpreted Python and compiled Codon on various DNA sequences, including mitochondrial DNA from humans and orangutans, as well as smaller test sequences. All algorithms use dynamic programming approaches with scoring parameters of +3 for matches, -3 for mismatches, -2 for gaps (or -5 gap open and -1 gap extend for affine gaps).

The main challenge of this assignment was the implementation time. Using the full contents of MT-human.fa and MT-orang.fa caused my pipeline to take over 30 minutes to complete half the testing. This, I thought was unneccesary and did not align with the goal of the assigment. I decided to only use the first 50 genome sequence lines from each, which resulted it much better, and more smooth pipeline testing and assignment completion, proving that Codon is more efficient than python for this task.
